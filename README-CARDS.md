# Animated profile README cards

The profile README uses self-contained SVG images generated by `scripts/render_readme_cards.py`.

## Generate

```bash
python scripts/render_readme_cards.py
```

Use `STATIC=1` to render the final frame without animation:

```bash
STATIC=1 python scripts/render_readme_cards.py
```

The renderer uses only the Python standard library and reads public contribution-calendar data from GitHub. It does not require a personal access token. If the live request fails, it uses `data/contributions.json` when present; otherwise it renders the activity cards without fabricated statistics.

## Automation

`.github/workflows/update-profile-readme.yml` refreshes the cards every day and can also be run manually from the Actions tab. It commits only changed files under `cards/`.

## Design

Cards use the 16alves02 dark palette with orange accent. All animations are embedded in each SVG, and are disabled for users who prefer reduced motion. The README keeps the original profile links, internship availability, project descriptions, stack, experience and academic work.
