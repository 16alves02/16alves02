# Animated profile README cards

The profile README uses self-contained SVG images generated by scripts/render_readme_cards.py.

## Generate

Run the renderer with Python 3.12 or newer:

    python scripts/render_readme_cards.py

Use STATIC=1 to render a still version for screenshots or visual review:

    STATIC=1 python scripts/render_readme_cards.py

The renderer uses only the Python standard library. It reads the public GitHub contribution calendar, parses dates/counts/levels, and caches the result in data/contributions.json. If GitHub is temporarily unavailable, the last valid cache is used. It never fabricates contribution totals.

## Tests

    python -m unittest discover -s tests -v

The tests cover HTML attribute-order differences, contribution tooltips, zero-contribution days and aggregate statistics.

## Automation

.github/workflows/update-profile-readme.yml validates the renderer and refreshes the SVG cards every day. It can also be run manually from the Actions tab after the workflow is merged into the default branch. Only changed generated cards and the contribution cache are committed.

## Design and accessibility

Cards use the 16alves02 dark palette with orange accent. Animation is embedded in each SVG and is disabled for users who prefer reduced motion. The README keeps the profile links, internship availability, project descriptions, stack, experience and academic work.
